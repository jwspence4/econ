\begin{enumerate}

\item (a) -- If a good is a necessity, that means there aren't many if any substitutes, so consumers can't reduce their demand much in response to a price increase. 

\setcounter{enumi}{0}

\item

	\begin{enumerate}
	
	\item I'd expect mystery novels to be more elastic because required textbooks aren't substitutable at all.
	
	\item I'd expect Billie Eilish recordings to be more elastic because they are a more narrowly defined good, so it's easier to find a substitute for Billie Eilish than it is pop music as a whole.
	
	\item I'd expect subway rides during the next five years to be more elastic because the longer time horizon gives people more time to change their behavior and find substitutes.
	
	\item I'd expect root beer to be more elastic because it is more of a luxury than water. 
	
	\end{enumerate}

\end{enumerate}
